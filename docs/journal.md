- PR n°7 (fusionnée) : groupes, rôles et accès croisé (voir [décision D14](decisions.md)). Les rôles de groupe passent dans une table d'appartenance (un compte peut être super admin d'un groupe et admin d'un autre) ; `GroupGuard` est la seule porte d'entrée vers les données d'un groupe et répond 404 identique que le groupe existe ou non. 82 tests dont 48 d'intégration, avec une série « accès croisé ».
